> **适用版本：v261015A**
> Windows 10/11 桌面字幕制作工作台
> 出品：天琴工作室（Lyra Studio）｜制作：海舟（Lyrazhou）

## 一、产品定位与版本范围

《弦字幕 Plus》（LyraSub Plus）是一款面向影视、访谈、课程、纪录片与长视频创作者的 Windows 本地字幕制作工具。它将本地语音识别、可选的大语言模型文本处理、可编辑的语义切分、时间轴校对、双语翻译、视频审片和 SRT 导出组织为连续工作流。用户可以在任何中间环节保存工程，之后继续完成文本校订、字幕切分、翻译或时间轴调整。

本说明书描述的是 **Plus 版**。在需要比较版本时，基础版必须称为 **《弦字幕（LyraSub）》**；本软件则称为 **《弦字幕 Plus》（LyraSub Plus）**。当前归档的安装程序与源码均对应《弦字幕 Plus》（LyraSub Plus），不应误称为《弦字幕（LyraSub）》的安装程序。

| 项目 | 《弦字幕（LyraSub）》 | 《弦字幕 Plus》（LyraSub Plus） |
|---|---|---|
| 核心定位 | 本地识别、文本处理、字幕切分、时间轴校对与 SRT 导出 | 在核心流程基础上扩展长片分段合并、视频审片、双语字幕、外部 SRT 工程与多 Profile 模型服务 |
| 输入 | 音频识别工作流 | MP3/WAV/MP4 识别，并可另行绑定高清 MP4 审片视频 |
| 翻译与双语 | 核心字幕制作为主 | 批量 LLM 翻译、译文独立校订、原文/译文/双语输出 |
| 项目组织 | 常规工程保存与继续制作 | 另存为、自动保存恢复、外部 SRT 人工定时工程、分段合并工程 |
| 审片能力 | 音频字幕校对 | 视频窗口、字幕安全区、音轨选择、字号与播放控制 |

## 二、安装、首次启动与模型准备

请运行完整安装程序 `LyraSub-Plus-setup.exe`，选择安装目录后完成安装。Plus 版沿用既有 LyraSub 的用户设置、模型与安装生态，以避免在同一台电脑上重复下载或重新配置。安装完成后，从开始菜单或桌面快捷方式启动《弦字幕 Plus》（LyraSub Plus）。

> **模型不随完整安装包强制预置。** 本地识别模型体积较大，首次使用时请在“本地模型管理”中按需要下载。之后同一模型会保存在当前 Windows 用户的应用数据位置，正常升级或重新安装通常无需重复下载。

| 准备项 | 建议 | 说明 |
|---|---|---|
| Windows | Windows 10 或 Windows 11 | 建议保持系统、显卡驱动和媒体组件为最新可用状态。 |
| 本地模型 | 快速、平衡或高精度模型按需下载 | 可根据素材时长、准确度与本机性能选择。 |
| 识别设备 | 优先尝试 GPU；失败时切换 CPU | NVIDIA GPU 环境不完整、显存不足或运行库不兼容时，CPU 仍可完成识别。 |
| 网络 | 仅在下载模型、调用在线 LLM 时需要 | 本地已下载模型后的识别不依赖在线 LLM。 |
| LLM 服务 | 可选 | 仅用于清洗、自然语义切分和翻译；不配置也可完成本地识别与手工编辑。 |

## 三、界面结构与工程原则

主窗口左侧为六阶段导航，中间为当前工作区，右侧为项目检查器。检查器会显示项目状态、字幕数量、锚点状态及当前启用的文本模型信息；如需要更多表格空间，可使用“隐藏检查器”折叠右侧区域。

六阶段工作流并非强制单向锁定。用户可以回到任一步修改内容；但当上游文本发生较大变动后，建议重新检查切分结果及时间轴状态。工程文件使用 `.lyrasub` 扩展名，保存其中间状态、字幕条目、锚点、译文、预览视频绑定、输出偏好和草稿信息，但不会把 LLM 密钥写入工程文件。

| 阶段 | 主要任务 | 产出或确认点 |
|---|---|---|
| 01 导入媒体 | 导入 MP3、WAV 或 MP4，设定项目名称 | 识别源媒体与项目名 |
| 02 语音识别 | 选择模型、主要语言与 GPU/CPU，开始本地识别 | 原始识别文本与词级时间锚点 |
| 03 文本清洗 | 可选调用 LLM 去口语化、规范表达 | 可编辑的清洗后文本 |
| 04 语义切分 | 按最大长度和语义生成字幕条目 | 可复核、拆分、合并的字幕行 |
| 05 校对导出 | 编辑文本与时间、翻译、审片、导出 SRT | 最终字幕与交付文件 |
| 06 分段合并 | 合并多章节 SRT 或工程 | 全片统一时间轴 SRT |

## 四、从媒体到识别文本

### 4.1 导入 MP3、WAV 或 MP4

在“01 导入媒体”中点击“导入媒体”，选择 MP3、WAV 或 MP4。WAV 可直接作为本地识别音源；MP4 将以其音轨作为识别来源；如后续需要用另一份清晰的高清视频审片，可在校对导出阶段再绑定预览 MP4。建议先在项目名称栏输入影片、章节或任务名称，以便保存工程和导出文件自动生成易识别的文件名。

从 v260822A 开始，所有常用打开、保存、另存、导出和分段合并对话框共享“最近操作文件夹”。成功选择文件或保存位置后，下一个文件对话框将默认打开该文件夹，减少跨目录反复定位的操作。

### 4.2 管理识别模型

点击顶部或相关页面的“本地模型管理”，从可用下载源选择模型并开始下载。下载任务提供进度、已用时间、停止按钮和可复制的错误文字。下载完成后，可继续下载其他模型；模型管理窗口不应阻塞主工作台。

选择识别模型后，可设置主要语言、设备和计算偏好。中文与英文是常用场景，工具亦可用于多语种音频。GPU 初始化失败时，先使用 CPU 完成工作；之后再检查 NVIDIA 驱动、CUDA、cuDNN 与应用兼容性。不要在识别过程中强行关闭程序；如需中断，请使用界面的停止按钮并保存已有工程。

### 4.3 开始识别与进度观察

点击“开始识别”后，程序会在本地模型中处理音频，并展示任务进度、当前状态、已用时与停止控件。识别结果不仅包含文本，也会保留尽可能细的词级时间锚点。后续语义切分会优先根据这些锚点继承条目的起止时间，因此不要仅把识别文本当成普通无时间信息的文稿。

## 五、文本清洗、编辑与提示词

### 5.1 清洗的用途

“03 文本清洗”是可选步骤。它适用于去除口语赘词、统一繁简或书面表达、修正常见识别错误。默认清洗策略保留自然的标点与阅读结构；这与后续字幕切分阶段的“去常规标点、以空格保留短语节奏”是不同的目标。

用户可以直接在编辑框中修改，也可以全选粘贴外部整理后的文本。轻微改写通常仍能借助文本对齐继续利用既有锚点；若整体替换为与原文差异很大的内容，程序会把不能可靠映射的部分标为需要人工复核或人工定时。对于大幅重写，建议在语义切分页检查黄色“需复核”行，并通过拆分、合并、修改或重新映射完成确认。

### 5.2 大字号编辑与提示词管理

清洗文本页面提供大字号编辑窗口，适合长文审阅。LLM 设置界面提供默认提示词模板的查看、编辑、保存与一键还原。用户自定义提示词会保留，不会被后续版本的默认模板自动覆盖。

| 提示词类型 | 建议用途 | 默认处理方向 |
|---|---|---|
| 清洗 | 去口语化、统一字形、纠正常见识别表达 | 保留必要标点和可读性 |
| 语义切分 | 形成自然、可读、节奏合理的字幕行 | 避免机械地每 15 字切一次；去除常规句读并以单空格保留短语连接 |
| 翻译 | 批量输出可回填的对应译文 | 保留数字、URL、撇号、连字符及必要特殊符号；去除普通句读 |

## 六、语义切分、锚点与人工复核

### 6.1 切分的工作方式

“最大字数”是柔性上限而不是机械截断位置。LLM 语义切分会参考语义边界、阅读节奏和字幕长度；例如短语可在一条字幕中以空格分隔，过长句子可自然拆分为多条，而不必平均切成固定字数。若不使用 LLM，也可以保留或手工调整切分结果。

每条字幕会尽可能继承其所覆盖文字或词语的时间锚点。“已继承”表示起止时间可从原始锚点可靠推导；“人工定时”表示用户直接设置或导入了时间；“需复核”表示文本修改、拆分或映射存在不确定性，需要用户确认。

### 6.2 复核、拆分与合并

在语义切分表中可右键目标行，选择修改文字、拆分、合并下一句或确认复核。双击文字时会打开较宽松的编辑窗口，避免受表格行高限制。完成后点击“应用切分修改并进入校对导出”，程序会保存表格改动、重新建立可用映射，并自动跳到“05 校对导出”。

> **锚点原则：** 修改字幕文本不会自动改变原始识别音频；程序会优先维持既有时间信息。对完全无对应关系的新文本，最安全的做法是使用人工定时并在预览中校正。

## 七、校对、时间轴编辑与视频审片

### 7.1 校对表格与插入字幕

校对表显示序号、原文、译文、开始时间、结束时间和时间状态。点击序号可让下方播放器跳到该字幕起点。用户可修改原文、译文以及起止时间；系统会检查相邻条目的逻辑围栏，以避免开始时间早于上一条结束时间、结束时间越过下一条起点，或形成非正时长字幕。

在音乐段落、静音段落或缺少识别文字的位置，暂停播放后可使用“插入”创建一条字幕；也可以对表格行右键使用“插入下一行”。新条目会在可用时间缝隙内生成起止时间，随后输入字幕文本即可。

### 7.2 外部高清视频与审片窗口

若项目最初用 MP3 识别，仍可在校对阶段选择一份 MP4 作为外部预览视频。视频审片窗口支持播放、暂停、停止、时间轴移动、音量调整、窗口最大化和字幕字号调整。双语输出时，预览会使用双行安全区，避免上下两行互相遮挡。

可选择预览声音来自“预览视频自身音轨”或“最初识别源媒体”。当高清视频与录音源不完全一致时，应先确认它们的时长与起点同步关系，再进行精细校对。

## 八、LLM Profile、批量翻译与双语字幕

### 8.1 Profile 与安全

“模型服务设置”支持多个 OpenAI-compatible API Profile。用户可新建、切换、编辑、删除 Profile，并导入官方或自定义 JSON 配置。当前生效 Profile 会统一用于清洗、自然语义切分和翻译。密钥与工程文件分离存储；请勿把含真实密钥的配置文件发送给不可信对象。

默认请求超时为 300 秒。短文本通常不需要调整；但若一次处理 30 分钟以上的长文本、服务端排队较久或网络条件有限，可在 Profile 设置中提高超时。对于超长影片，推荐按章节或媒体段落分别制作工程，再在“06 分段合并”统一时间轴。

### 8.2 选择目标语言

目标语言控件采用固定下拉菜单，提供英语、日语、韩语、法语、德语、西班牙语、俄语、繁体中文等常用选项。最后一项为“自定义语言…”。选择该项后，会打开独立输入框；请以中文或英文写入目标语言名称，例如“阿拉伯语”或“Portuguese (Brazil)”。

该交互不会在用户逐字输入时反复刷新表格、预览或工程状态，因此避免了旧式可编辑文本框可能出现的短暂停顿。普通语言选择或确认自定义语言后，仅会触发一次必要的字幕输出设置更新。

### 8.3 批量翻译与失败恢复

翻译会依据字幕边界打包请求，而不会逐条调用模型。默认每批为 2000 个原文字符，中文、英文、空格和标点均计入字符数。这不是 token 数；不同模型的上下文限制、输出速度和 JSON 稳定性仍可能不同。

若模型返回的 JSON 被截断、翻译数组缺失、条目 ID 不完整或正文缺失，程序会将可重试的批次自动二分缩小后重新请求。所有批次都成功后，译文才会统一写回工程，避免只写入半份翻译结果。译文与原文共享同一条字幕的时间轴，用户可在校对表单独修订译文，不会改变原文锚点或时间。

### 8.4 输出模式

在校对导出页可选择原文、仅译文或双语两行。已生成译文后，切换输出模式不需要再次调用 LLM；系统只是改变导出和预览的显示方式。双语模式可设置原文在上、译文在下，或译文在上、原文在下。

| 输出模式 | 导出内容 | 是否需要重新翻译 |
|---|---|---|
| 原文 | 使用原字幕文本 | 否 |
| 译文 | 使用已有译文文本 | 否；前提是已翻译 |
| 双语两行 | 同一时间轴内原文与译文各占一行 | 否；前提是已翻译 |

## 九、外部 SRT 与分段合并

### 9.1 导入外部 SRT

可直接导入外部 SRT，系统会按其既有时间码生成字幕条目。由于外部 SRT 并不天然包含本项目的识别词级锚点，因此这些条目显示为人工定时；这不是错误，而是对已有时间码的正确尊重。导入后可保存为 `.lyrasub` 工程，继续校对、翻译、预览和导出。

### 9.2 分段合并

处理电影级长片时，建议将每一章节单独识别、校对并保存。随后在“06 分段合并”加入章节 SRT 或章节 `.lyrasub` 工程，为每段填写其在全片中的起点。第二段本地 `00:00:00` 会被映射到“全片起点”，从而避免多个章节都从零开始造成时间轴冲突。

分段合并支持查看全局条目、调整章节起点、保存 `.lyrasubmerge` 合并工程并导出全片 SRT。若章节之间存在片头、空白、插曲或转场，应将这些时长计入下一章节的全片起点。

## 十、保存、自动保存、另存为与归档

请在项目首次形成有效内容后尽早保存。普通“保存”会更新当前 `.lyrasub`；“另存为”会创建分支副本，适合保留不同语言、不同剪辑版或不同校订方案。自动保存的间隔可在菜单中设置；恢复文件用于意外退出后的继续工作，不应替代用户主动保存的正式工程。

归档时建议同时保存源媒体路径说明、正式 `.lyrasub` 工程、最终 SRT、所用 LLM 提示词或不含密钥的 Profile 示例，以及导出版本说明。模型文件可独立保留，但不属于普通项目工程的一部分。

## 十一、常见问题与排障

| 现象 | 常见原因 | 建议处理 |
|---|---|---|
| 识别提示缺少组件或模型 | 本地模型尚未下载或运行环境不完整 | 打开“本地模型管理”下载所需模型；检查错误文本。 |
| GPU 初始化失败 | 驱动、CUDA/cuDNN、显存或兼容性问题 | 先切换 CPU 完成任务，再按错误信息检查 GPU 环境。 |
| LLM 返回 JSON 截断或条目缺失 | 批次过大、模型输出限制、网络/服务不稳定 | 将翻译批次调小；确认模型支持足够 JSON 输出；稍后重试。 |
| 目标语言选择时界面停顿 | 使用旧版本的可编辑输入交互 | 升级至 v260822A 或更高版本，并使用固定下拉或“自定义语言…”。 |
| 打开/导出总从错误目录开始 | 最近目录尚未由成功选择更新 | 完成一次真实打开或保存操作；之后所有常用文件对话框共用该位置。 |
| 外部 SRT 显示人工定时 | 外部文件没有本项目识别锚点 | 正常现象；在校对页调整时间即可。 |
| 视频字幕不同步 | 视频与识别音频起点、剪辑或帧率不同 | 确认使用的预览音轨及媒体版本，必要时调整字幕时间或重新匹配素材。 |

## 十二、交付前检查清单

在最终导出前，建议完整播放或抽查开头、中段、结尾，确认字幕没有跨镜头过长停留、没有相邻重叠、双语两行没有遮挡，并确保输出模式符合交付要求。最后将正式工程另存为归档版本，再导出 SRT。

| 检查项 | 建议状态 |
|---|---|
| 项目名称、工程路径和媒体版本已确认 | 完成 |
| 识别文本与清洗文本已核对 | 完成 |
| “需复核”或人工定时条目已检查 | 完成 |
| 翻译语言、译文质量和双语顺序已确认 | 按需完成 |
| 预览视频、音轨来源、字号和安全区已检查 | 按需完成 |
| `.lyrasub` 工程、最终 SRT 与归档副本已保存 | 完成 |
