## 一、品牌定位

《弦字幕 Plus》（LyraSub Plus）面向希望把字幕制作做得更快、更稳、更可控的影视创作者、纪录片团队、课程制作人、访谈栏目和独立后期工作者。它以本地语音识别为基础，将文本清洗、自然语义切分、时间轴校对、双语翻译、视频审片和长片分段合并整合进同一套 Windows 桌面工作流。

> **核心主张：** 让字幕从“识别出来”走向“真正可以交付”。

| 品牌关键词 | 可传达的价值 |

| 影视工作流 | 不止生成文本，还支持语义切分、时间轴校对、视频审片和 SRT 交付。 |

### 4.4 应用商店/官网长介绍

字幕制作的难处，从来不只是把声音识别成文字。真正的交付还需要自然的断句、可信的时间轴、可读的双语排版、结合画面的审片，以及长片项目的稳定组织方式。

《弦字幕 Plus》（LyraSub Plus）围绕这些真实制作环节设计。用户可以导入 MP3、WAV 或 MP4，使用本地模型生成文本和词级时间锚点；必要时通过 OpenAI-compatible LLM 完成清洗、自然语义切分和批量翻译；随后在校对页逐条调整文本与时间，并在视频窗口中检查字幕与画面的关系。已翻译的译文与原文共享同一时间轴，支持原文、译文、双语两行 SRT 输出，也允许独立修订译文。

对于长片和多章节项目，Plus 版提供独立的分段合并模块。每个章节可单独识别与校对，再指定其在全片中的起点，最终合并出一份完整、连续的 SRT。工程支持保存、自动保存恢复和另存为，让字幕流程能够适配真实的反复修改与版本管理。

## 九、FAQ 宣传问答

### 它和普通“语音转文字”有什么不同？

《弦字幕 Plus》（LyraSub Plus）不仅生成文本，也保留和编辑字幕的时间轴信息；它把自然切分、时间校对、翻译、视频审片和 SRT 导出串成一条制作流程。

### 是否一定需要在线接口？

不一定。本地模型可以完成语音识别。在线 OpenAI-compatible 服务用于可选的文本清洗、语义切分和批量翻译。

### Plus 版适合谁？

适合需要双语字幕、高清视频审片、外部 SRT 工程、长片分段合并或多套 LLM Profile 的创作者、字幕师和制作团队。
