# 《弦字幕 Plus》v260821J 发布说明

**版本：v260821J**  
**产品：弦字幕 Plus（LyraSub Plus）**  
**发布形式：v260821I → v260821J 累积差分补丁**

> 本版本重点完善双语字幕的人工校对与影视审片体验，并降低不同 OpenAI 兼容服务在长篇翻译时发生不完整 JSON 返回的概率。

## 本版新增与优化

| 功能 | v260821J 行为 |
|---|---|
| 译文独立校对 | “校对导出”表格新增 **译文** 列。双击译文，或右键选择“修改译文”，可单独修改该条译文。修改不会触发原文锚点重映射，也不会改变时间轴。 |
| 译文保护 | 翻译范围默认设为 **仅翻译空白译文**，保护已由人工校对的内容；需要重翻时可选择“翻译全部并覆盖现有译文”。 |
| 默认翻译批次 | 新建 Profile、旧 Profile 缺省值和导入 JSON 缺省值统一为 **2000 字符**。字符数按原字幕文本逐字符计算，中文、英文、空格和标点都计入，不是 Token 数。 |
| 自适应缩批重试 | 当模型返回 JSON 截断、缺少 `translations` 数组、缺少唯一 ID/文本，或译文 ID 集合不完整时，系统会将失败批次按字幕边界二分后自动重试。单条字幕仍失败时才报告错误。 |
| 目标语言选择 | 目标语言改为可编辑下拉框，提供英语、日语、韩语、法语、德语、西班牙语、俄语和繁体中文等常用项，仍可手工输入中文或英文的任意语言名称。 |
| 视频审片窗口 | 独立视频预览窗口支持 Windows 最大化，并增加播放/暂停、停止、时间轴、时间显示、音量和字幕字号控制。所有控件与校对页共享同一播放时间轴。 |
| 音轨来源 | 外部 MP4 预览时可选择听 **视频音轨** 或 **识别源音轨**。默认使用视频音轨；选择识别源音轨时，系统以同一播放位置同步最初导入的 MP3/MP4 音频。 |
| 双语字幕安全区 | 双语模式下，校对页和视频审片窗口预留更高的字幕安全区。审片窗口字幕字号可调为 16–64 px，安全区随字号动态扩展，避免第二行被裁切。 |

## 翻译失败时的自动处理

此前服务端可能在生成较长 JSON 后返回不闭合的字符串，表现为 `Unterminated string ...`；也可能返回部分翻译条目而缺少 ID 或文本。v260821J 不会把这样的半成品写入工程。

翻译先按 Profile 的批次上限分组。若某一组因上述可恢复错误失败，并且该组包含至少两条字幕，系统会显示“自动拆分后重试”的进度提示，并将它拆成两组继续请求。所有翻译条目都必须经 ID 一一对应校验；只有全部成功后，译文才一次性写入工程。

| 情况 | 系统行为 |
|---|---|
| 2000 字符批次成功 | 正常写入全部译文。 |
| 一批返回不完整 JSON | 自动按字幕条目边界拆成两批重试。 |
| 一批包含缺失 ID/空译文 | 自动拆成更小批次重试。 |
| 单条字幕仍持续返回无效结构 | 停止该任务并报告错误；不会写入半成品。可更换服务、缩短该条原文或人工填写译文。 |
| 用户点击停止 | 任务停止，未完成结果不会写入工程。 |

## 译文校对流程

完成 LLM 翻译后，进入 **校对导出** 页面。表格中的“原文字幕”和“译文”分开显示；空译文会标注“未翻译；双击可手动填写”。编辑译文不会改变语音识别锚点、字幕开始/结束时间、人工定时状态或原文内容。

> 建议流程：先使用“仅翻译空白译文”生成初稿，再逐条校对重点字幕。以后即使再次点击 LLM 批量翻译，默认也只补全空白译文；只有明确切换到“翻译全部并覆盖现有译文”才会覆盖人工修改。

## 视频审片与音轨

导入外部高清 MP4 后，视频画面默认配合该 MP4 内嵌音轨播放。若识别时使用的是单独 MP3，且希望听最初的识别源音频，可在校对预览区选择 **音频：识别源**。该模式要求外部视频和识别源来自同一剪辑版本、起点一致；若片头、删减或帧率版本不同，画面、音频和字幕可能产生相对错位，需要用户自行选择正确素材。

视频审片窗口可以最大化。窗口内的播放、停止、时间轴和音量与主校对页同步；“停止”会暂停并回到起点。双语预览采用固定原文/译文两行结构，审片窗口的字幕安全区会依照当前字体大小保留至少两行空间。若单独某一行文字过长而发生额外折行，建议在译文列中缩短、润色后再导出。

## 工程兼容性与验证

工程格式升级为 **schema v6**，新增项目级 `preview_audio_source` 设置。旧工程可继续打开，默认按“视频音轨”处理；原有译文、双语输出、外部预览视频和多 Profile 配置保持兼容。

本版本已完成 Python 格式化和静态检查；完整测试 **67 项通过**，离屏界面冒烟测试 **23 项通过**。测试覆盖 schema v6 持久化、译文列与双语安全区、审片窗口控件、外部视频绑定后的识别源音轨选择、默认 2000 字符批次，以及 JSON 截断和“缺少唯一 ID 或文本”的缩批重试判定。
