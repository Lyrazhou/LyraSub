# 《弦字幕 Plus》v260821I 发布说明

**版本：v260821I**  
**产品：弦字幕 Plus（LyraSub Plus）**  
**发布形式：v260821H → v260821I 累积差分补丁**

> 本版本为 OpenAI 兼容模型服务配置加入可持久化的多 Profile 管理。用户现在可以保存多套 API 服务，随时在下拉菜单中切换当前使用项，并对任意 Profile 进行修改或删除。

## 新增能力

| 能力 | 说明 |
|---|---|
| 多 Profile 保存 | 每套 Profile 独立保存名称、API 基础地址、模型名称、附加请求头、超时和翻译每批字符数。 |
| 当前配置下拉选择 | 在“模型服务”窗口顶部通过“当前 Profile”下拉菜单切换活动项。切换会立即保存，之后的 LLM 任务将使用该项。 |
| 新建 Profile | 点击“新建 Profile”，填写新的服务参数及 API 密钥后点击“保存当前 Profile”。新建项会自动成为当前活动配置。 |
| 修改 Profile | 在下拉菜单选中已有 Profile 后，直接修改表单并保存。若 API 密钥留空，将保留该 Profile 已保存的密钥。 |
| 删除 Profile | 选择 Profile 后点击“删除当前”，确认后会同时删除该 Profile 的本地 API 密钥。若删除当前活动项，系统会自动切换到剩余的第一项；没有剩余项时活动配置为空。 |
| 安全存储 | API 密钥仍独立保存在当前 Windows 用户的受保护本地存储中，不写入 `.lyrasub` 工程文件，也不会在默认 Profile 导出中泄露。 |

## 使用步骤

从顶部工具栏打开 **模型服务**。窗口上方的 **Profile 管理** 区显示“当前 Profile”下拉菜单。首次使用时直接填写表单并保存，即可创建首个 Profile。之后如需增加服务商、模型或不同账号，点击 **新建 Profile**；如需切换，选择下拉菜单中的名称；如需修改，先选择目标项、编辑字段、保存；如需移除，选择目标项并点击 **删除当前**。

“当前 Profile”不是仅供编辑器显示的临时状态，而是持久化的全局活动选择。关闭软件、重新打开工程或重启应用后，系统会恢复该选择。**LLM 清洗、LLM 自然语义切分和 LLM 批量翻译均统一读取当前活动 Profile。**

| 字段 | 保存位置 | 修改规则 |
|---|---|---|
| Profile 名称、地址、模型、请求头、超时、翻译批次字符数 | 本机 `llm_profiles.json` 配置 | 选择 Profile 后可编辑并保存。 |
| API 密钥 | 当前 Windows 用户受保护密钥存储 | 修改密钥时填写新值；留空则保留原值。删除 Profile 时一并删除。 |
| 当前活动 Profile ID | 本机 `llm_profiles.json` 配置 | 通过下拉选择或保存新/修改 Profile 时更新。 |
| 字幕工程文件 | `.lyrasub` | 不保存任何 API 密钥或 Profile 私密内容。 |

## 兼容性与验证

既有仅含 `profiles` 数组的模型服务配置继续可用。首次进入新版模型服务窗口时，如没有保存过活动项，系统会自动将第一套已有 Profile 作为当前项；随后会按新的 `active_profile_id` 字段保存选择状态。

本版本已完成 Python 格式化和静态检查；完整测试 **65 项通过**，离屏界面冒烟测试 **22 项通过**。回归测试覆盖多 Profile 保存、活动选择的重启恢复、删除当前项后的回退，以及界面下拉切换和删除交互。
