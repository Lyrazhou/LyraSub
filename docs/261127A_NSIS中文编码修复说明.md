# 《弦字幕 Plus》（LyraSub Plus）v261127A NSIS 中文编码修复说明

## 修复内容

v261126A 安装器界面、卸载项及快捷方式中的中文出现乱码。检查发现 `installer/setup.nsi` 虽为 UTF-8 文本，但没有 UTF-8 BOM；在 Windows runner 的 NSIS 编译环境中，中文字符串因此可能按系统 ANSI 代码页解释。

本版将 NSIS 脚本统一保存为 **UTF-8 with BOM**，并保留 `Unicode true`。Windows 构建会在编译前验证 UTF-8 BOM；安装后检查开始菜单和桌面是否存在名称准确的“弦字幕 Plus（LyraSub Plus）”快捷方式，并检查卸载注册表显示名。

升级安装会清除旧版可能产生的乱码 `.lnk` 快捷方式，再创建正确中文名称的快捷方式。安装器仍复用 `$LOCALAPPDATA\LyraSub`，只替换应用自有文件，不清除模型或工程用户文件。

## 版本与交付

- 软件版本：`v261127A`
- 构建：`Build 1`
- 安装器：`261127A_LyraSub-Plus-setup.exe`
- 发布方式：构建、静默安装与中文名称检查全部通过后，创建 GitHub Release，并附安装器、源码 ZIP 与 SHA-256 清单。

## 验证要求

1. 单元测试、Qt 离屏测试、Ruff 检查全部通过。
2. NSIS 源脚本带 UTF-8 BOM，且 `Unicode true` 已启用。
3. 冻结目录和静默安装目录的识别运行时导入自检通过。
4. 安装器是有效 Windows PE 文件；安装清单版本为 `v261127A`。
5. 开始菜单快捷方式、桌面快捷方式和卸载注册表显示名均包含正确中文。
6. 安装后的应用可启动；安装与升级保留用户模型和项目数据。
