# 《弦字幕 Plus》（LyraSub Plus）v261126A 源码归档说明

> 本文档对应《弦字幕 Plus》（LyraSub Plus）v261126A 完整程序源码归档。基础版在对比语境中统一写作 **《弦字幕（LyraSub）》**。

## 一、归档目的与边界

归档用于保存可审阅、可继续维护的源码、测试、Windows 安装脚本、构建脚本及用户文档。不包含构建输出、Wine 前缀、Python/测试缓存、已编译安装程序、本地识别模型或真实 API 密钥。安装程序沿用既有安装目录与用户模型位置，安装升级不主动清除用户模型和项目文件。

## 二、本版变更

校对导出时间输入与显示统一使用 `HH:MM:SS.mmm`；开始时间提供“上条结束时间”快捷按钮，按上一条结束 +1ms 设置；结束时间提供“下条开始时间”快捷按钮，按下一条开始 −1ms 设置。第一条/末条对应按钮禁用。快捷设置违反时间围栏或导致非正时长时会提示并拒绝修改，保存无效时间也会阻止关闭编辑对话框。工程数据仍以毫秒整数保存。

本版还修复 Windows 识别模块导入前未注册冻结应用 DLL 搜索目录的问题，并让导入失败时保留原始异常。Windows 构建会在打包目录和静默安装目录分别运行识别依赖导入自检；自检失败将阻止安装器上传。

## 五、开发环境与质量检查

项目使用 Python 3.12、PySide6、PyInstaller、NSIS、pytest 与 Ruff。标准离屏测试命令：

```bash
ruff check src tests
ruff format --check src tests
QT_QPA_PLATFORM=offscreen pytest -q
```

v261126A 的回归范围包括毫秒时间码解析/格式化、相邻行边界快捷按钮启用状态、精确 ±1ms 修改、越界/无效时长拒绝、工程时间围栏及既有完整应用回归测试。Windows 包构建前必须通过以上测试和 Ruff 检查。

## 六、Windows x64 构建及安装验证

`.github/workflows/windows-installer.yml` 使用 GitHub 托管 Windows runner 安装 Python 3.12 与 NSIS，运行测试和静态检查、构建 PyInstaller 应用目录、校验 OpenCC，并从冻结程序执行 `--diagnose-recognition-runtime`。生成安装器后，工作流会验证 PE 文件、静默安装、安装清单，再从安装目录执行同一识别运行时自检并启动应用。任一识别依赖导入失败都会阻止 artifact 上传。

完成后从 Actions workflow run 下载 `v261126A-windows-x64-installer` artifact（含安装器和 manifest）。Artifact 仅保留 14 天。该流程明确不创建 GitHub Release，不上传安装程序到 Release。

升级安装沿用 `$LOCALAPPDATA\\LyraSub` 与原注册表路径，安装器只替换应用文件和快捷方式，不删除模型及项目用户数据。卸载程序保留用户应用数据中的本地识别模型。
