# 《弦字幕 Plus》（LyraSub Plus）简要介绍、快速上手与版本对比

> **适用版本：v260822A**  
> 本指南面向首次安装、快速完成一段字幕，以及需要向团队说明版本差异的用户。

## 一、30 秒认识产品

《弦字幕 Plus》（LyraSub Plus）是一套面向影视字幕制作的 Windows 工作台。它可导入 MP3 或 MP4，通过本地语音识别生成可编辑文本和时间锚点，再借助可选的 LLM 完成清洗、自然语义切分与批量翻译，最终导出原文、译文或双语 SRT。对于长片项目，Plus 版还能将多章节工程或 SRT 统一到同一全片时间轴，并在视频窗口内完成审片。

> **一句话定位：** 把“音频识别—文本整理—字幕切分—时间轴校对—双语翻译—视频审片—SRT 交付”收拢到一套可保存、可回退、可继续的本地桌面工作流中。

## 二、《弦字幕（LyraSub）》与《弦字幕 Plus》（LyraSub Plus）：如何正确区分

请注意，基础版名称必须完整写作 **《弦字幕（LyraSub）》**；Plus 版名称完整写作 **《弦字幕 Plus》（LyraSub Plus）**。当前 v260822A 归档交付的是 Plus 版安装程序和源码。

| 能力维度 | 《弦字幕（LyraSub）》 | 《弦字幕 Plus》（LyraSub Plus） |
|---|---|---|
| 核心制作链路 | 本地语音识别、文本清洗、语义切分、锚点校对、SRT 导出 | 完整保留，并扩展复杂影视交付能力 |
| 媒体导入 | 常规音频字幕任务 | MP3/MP4 识别；可在后期另外绑定高清视频预览 |
| 工程机制 | 保存并继续常规字幕工程 | 自动保存恢复、工程另存为、外部 SRT 人工定时工程、分段合并工程 |
| LLM 配置 | 可选文本处理服务 | 多套 Profile 保存、切换、编辑、删除与 JSON 配置导入 |
| 翻译交付 | 核心流程外的扩展需求 | 批量翻译、译文独立编辑、原文/译文/双语两行输出 |
| 视频审片 | 以字幕制作流程为重点 | 视频窗口、播放/停止、时间轴、音轨来源、字幕字号和双语安全区 |
| 长片工作方式 | 可按章制作 | 支持为各章节指定全片起点，并合并为一份全片 SRT |

## 三、10 分钟快速上手

### 第 1 步：先准备模型，再创建项目

启动《弦字幕 Plus》（LyraSub Plus）后，打开“本地模型管理”，下载适合本机与任务的识别模型。若使用 NVIDIA GPU，可先选择 GPU；若初始化失败，切换 CPU 后仍可继续工作。模型需要单独下载，完整安装包不会强制内置大型模型文件。

### 第 2 步：导入媒体并命名

在“01 导入媒体”选择 MP3 或 MP4，随后输入项目名称，例如“纪录片-第一章”。从 v260822A 起，软件会记住上一次成功打开、保存或导出的文件夹，之后的常用文件对话框会自动定位到这个目录。

### 第 3 步：选择识别参数并开始识别

在“02 语音识别”选择已下载模型、主要语言及 GPU/CPU。点击开始后观察进度与已用时；如果需要停止，请使用界面上的停止按钮。识别完成后，软件保留的不只是文本，还包括后续生成字幕时间码所需的词级时间锚点。

### 第 4 步：按需要清洗文本

在“03 文本清洗”直接修改识别文本，或配置 OpenAI-compatible LLM 后使用清洗功能。清洗是可选步骤；如果识别文本已可用，可直接前往语义切分。长文编辑可打开大字号编辑窗口。

### 第 5 步：生成自然字幕行

在“04 语义切分”设置每行最大字数，点击“自然语义切分”。最大字数是柔性上限，程序会优先按短语、语义和阅读节奏切分，而不是每隔固定字数硬拆。黄色或“需复核”的行应逐一检查；可右键拆分、合并、修改文字或确认复核。

### 第 6 步：校对时间并导出

点击“应用切分修改并进入校对导出”。在“05 校对导出”中点击序号可定位播放器；可修改字幕文本、起止时间，并在静音段落插入新字幕。确认后选择原文、译文或双语模式，点击导出 SRT。

| 快速目标 | 最少操作路径 |
|---|---|
| 一份中文 SRT | 导入 MP3/MP4 → 识别 → 语义切分 → 校对 → 原文 SRT 导出 |
| 一份英文字幕 | 完成原文校对 → 选择英语 → 批量翻译 → 校对译文 → 译文 SRT 导出 |
| 双语 SRT | 完成翻译 → 选择双语两行与上下顺序 → 检查预览 → 导出 SRT |
| 高清视频审片 | 先完成字幕工程 → 校对页选择预览 MP4 → 调整音轨/字号 → 播放检查 |
| 长片合并 | 每章独立制作 → 进入分段合并 → 指定各章全片起点 → 导出全片 SRT |

## 四、翻译目标语言：v260822A 的正确操作

目标语言现在不是可自由敲字的实时文本框，而是稳定的下拉菜单。请选择英语、日语、韩语、法语、德语、西班牙语、俄语或繁体中文等常用项目；如需其他语言，请选择最后一项“自定义语言…”，再在弹出的输入框中输入“阿拉伯语”“葡萄牙语（巴西）”或英文语言名称。

这样设计的好处是：确认选择前不会不断刷新校对表、预览和工程状态，避免旧交互中逐字输入语言名称可能造成的短暂停顿。已翻译完成后，改为原文、译文或双语输出只影响显示和导出方式，无需重复翻译。

## 五、三个实用建议

| 场景 | 建议 |
|---|---|
| 访谈、课程、短视频 | 使用单一工程完成识别、切分和校对；先抽查开头、中段、结尾。 |
| 电影、长纪录片 | 按章节建立多个工程，保留各章源文件与工程，再用 Plus 分段合并功能统一时间码。 |
| 团队协作 | 交接时同时提供 `.lyrasub` 工程、最终 SRT、所用媒体版本说明和不含密钥的 Profile 示例。 |

## 六、常见疑问

### 我一定要配置在线 LLM 吗？

不一定。本地识别、手工文本编辑、手工切分、时间校对和 SRT 导出均可完成。LLM 的价值在于加快文本清洗、自然语义切分和批量翻译。

### 为什么导入外部 SRT 后显示“人工定时”？

外部 SRT 已拥有自己的时间码，但没有当前识别工程的词级锚点。软件将其标记为人工定时，是为了保留原 SRT 的真实时间轴，而不是把它错误地伪装成自动继承结果。

### 安装包为什么不含识别模型？

模型文件较大，且不同用户对速度和准确度的需求不同。软件将模型下载与完整安装包分离，首次选择需要的模型即可；之后同一用户环境会复用已下载模型。

### 《弦字幕（LyraSub）》的正确名称是什么？

在全部说明、宣传和对比材料中，应完整写作 **《弦字幕（LyraSub）》**，不要省略中文书名号内的英文名，也不要写成不完整的“基础版”或“弦字幕”。
