# 《弦字幕》（LyraSub）v260820C 网络下载诊断补丁说明

**补丁文件：** `LyraSub-patch.exe`  
**升级路径：** `v260820` → `v260820C`  
**适用情况：** 官方源、国内镜像源或 VPN 环境下均提示无法下载模型，或此前出现“无法在 Hub 找到文件/本地缓存不存在”。

## 本次实际修复

此前版本使用 Hugging Face Hub 客户端的 `snapshot_download` 接口。经 Windows 运行时复现，模型 API 与模型文件地址都能访问，但该客户端在解析文件重定向/Xet 元数据时错误抛出 `FileMetadataError`，随后包装成“本地缓存不存在”。因此，地址本身未必有问题，VPN 也未必能修复该程序内部错误。

v260820C 不再使用该失败路径。软件会先直接读取模型仓库清单，再逐个下载模型文件，允许标准 HTTPS 重定向，并在界面中显示当前文件、已下载大小、总大小与百分比。该方案已经在 Windows 运行时从国内镜像完整下载“快速”模型并通过完整性检查。

| 新增能力 | 行为 |
|---|---|
| 实时进度条 | 显示当前文件及 0–100% 进度；大文件 `model.bin` 会显示已下载 MB / 总 MB。 |
| 停止下载 | 点击“停止下载”后，当前临时文件会被清理，且不会被误当作已完成模型。 |
| 可复制诊断 | 下载或连接失败时会打开可选中文本框；点击“复制诊断”即可复制完整信息。 |
| 可选代理 | 支持 `http://` 或 `https://` 代理地址，例如 `http://127.0.0.1:7890`。 |
| 三档模型 | 快速、平衡、高精度均支持分别下载并复用。 |

## 使用步骤

请完全退出《弦字幕》后运行 `LyraSub-patch.exe`。打开软件，在 **02 文字识别** 页面选择模型档位和来源，然后点击“测试连接”。如果连接正常，点击“下载选中模型”。下载过程中不要关闭软件；如需中止，点击“停止下载”。

连接或下载失败时，请在弹出的“模型下载诊断”窗口中点击“复制诊断”，将完整文本发送给开发者。不要只发送最前面的一行提示，因为 URL、HTTP 状态、最终重定向地址、代理设置和原始异常信息才是定位问题所需内容。
