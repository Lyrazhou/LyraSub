# 《弦字幕》（LyraSub）v260820E 补丁说明

> **适用版本：** 已安装 **v260820D** 的《弦字幕》（LyraSub）。本补丁固定文件名为 `LyraSub-patch.exe`，执行后将应用升级为 **v260820E**。

## 本次更新概览

v260820E 将此前分散在各功能页的等待状态统一为可见、可估时、可停止的任务体验，并为 NVIDIA GPU 初始化失败提供可复制的完整诊断报告。识别、LLM 文本清洗、LLM 语义切分、本地切分及时间锚点映射、模型下载和 GPU 自检均通过同一后台任务框架运行，避免长任务阻塞工作台。

| 更新类别 | v260820E 内容 |
|---|---|
| 全流程进度 | 工作台顶部新增统一任务横幅，显示任务名称、当前阶段、进度百分比、已用时与预计剩余时间。未能量化的操作显示持续处理中状态。 |
| 安全停止 | 所有长任务均提供“停止当前任务”按钮。停止请求在安全检查点生效，未确认的识别、清洗、切分或锚点映射结果不会写入项目。 |
| 识别进度 | 本地识别会读取音频总时长，并根据已处理音频时间显示百分比与时间进度。 |
| LLM 进度 | 文本清洗和语义切分分别显示连接服务、请求生成、解析响应和锚点映射等阶段。 |
| 切分与锚点 | 本地切分与 LLM 切分后的词级时间锚点映射已移至可停止后台任务；用户的字幕时间依据仍永久保留。 |
| GPU 自检 | “模型与设备”页新增 NVIDIA GPU 环境自检，检查 `nvidia-smi`、CUDA 12 的 `cublas64_12.dll` 与 `cublasLt64_12.dll`、cuDNN 9 的 `cudnn64_9.dll`，以及 CTranslate2 可见设备数。 |
| 可复制诊断 | 模型下载、GPU 自检和后台任务失败均使用可复制的诊断窗口。GTX 1060 等设备的 GPU 初始化失败不再只显示笼统错误。 |
| 稳定性 | 识别完成后的自动本地切分会等待识别任务彻底释放后再调度，避免连续任务之间的界面或线程竞争。 |

## 升级方法

请先**完全退出**正在运行的《弦字幕》。随后双击 `LyraSub-patch.exe`，按安装向导完成更新即可。补丁会先检查当前安装版本是否为 **v260820D**；若版本不匹配，为避免覆盖错误文件，补丁将终止而不作修改。

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 关闭《弦字幕》 | 避免程序占用文件。 |
| 2 | 双击运行 `LyraSub-patch.exe` | 显示 v260820E 补丁安装向导。 |
| 3 | 完成安装 | 应用目录中的变更文件被替换，注册表版本更新为 v260820E。 |
| 4 | 启动《弦字幕》 | 在“关于”信息或界面版本标识中确认版本为 v260820E。 |
| 5 | 打开“模型与设备”页 | 可使用“NVIDIA GPU 环境自检”复制本机 GPU 运行时诊断。 |

## GPU 自检说明

选择 **NVIDIA GPU** 时，如果运行时不可用，应用会弹出可复制诊断。对于 GTX 1060，建议重点确认 NVIDIA 驱动正常工作，且系统可找到 CUDA 12 与 cuDNN 9 所需 DLL。CPU 模式不依赖这些组件；使用“自动”模式时，GPU 环境不合格会自动回退到 CPU 并在状态提示中说明原因。

> GPU 自检仅检查本机可见的运行时条件，不会安装驱动、CUDA 或 cuDNN，也不会更改系统环境变量。

## 回滚与备份

补丁会在应用安装目录创建 `.update-backup\v260820E`。其中保存本次覆盖前的 `LyraSub.exe`、`release-manifest.json` 和 `patch-info.txt`，用于人工核对或在技术支持指导下回退。补丁不会修改用户项目文件、音频文件、已下载的模型或本地 LLM 配置。
