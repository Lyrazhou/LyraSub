# 《弦字幕》（LyraSub）v260820 模型下载补丁说明

**补丁文件：** `LyraSub-patch.exe`  
**适用对象：** 已安装 v260820 基准版的用户；即使此前安装过旧的同名补丁，也可以直接运行本补丁。  
**模型是否内置：** 不内置。快速、平衡和高精度三个模型均由用户按需下载，并在当前 Windows 用户目录中长期复用。

## 本次改进

本补丁将原来“点击识别后隐式从单一站点下载模型”的方式，改为在“文字识别”页内明确显示模型、预计大小、模型来源、连接测试和下载状态。软件不再把网络失败误显示成“缺少识别运行组件”；当模型未下载时，会提示您先选择来源并下载。

| 模型档位 | 适用场景 | 预计下载量 | 模型仓库 |
|---|---|---:|---|
| 快速 | 草稿转写、短片测试 | 约 150 MB | `Systran/faster-whisper-base` |
| 平衡（默认） | 常规中英文影视对白 | 约 470 MB | `Systran/faster-whisper-small` |
| 高精度 | 最终校对前的高质量识别 | 约 1.5 GB | `Systran/faster-whisper-medium` |

> 表中为下载前的近似大小，实际大小会因仓库版本、镜像响应和缓存状态略有差异。三个模型可以分别下载，也可以按需要全部下载；更新补丁不会删除模型。

## 中国境内的使用步骤

请完全退出《弦字幕》后运行 `LyraSub-patch.exe`，再重新启动软件，进入 **02 文字识别**。选择一个模型档位，再按网络环境选择模型来源。

| 模型来源 | 适用情况 | 操作建议 |
|---|---|---|
| 国内镜像源 | 中国境内普通网络 | 默认选项。先点击“测试连接”，成功后点击“下载选中模型”。 |
| 官方源（适合可直连 / VPN） | VPN 或可稳定访问 Hugging Face 的网络 | 确保 VPN/代理已对《弦字幕》进程生效，再测试连接和下载。 |
| 自定义地址 | 企业代理、私有镜像或可信的其他兼容服务 | 选择“自定义地址”，填写以 `https://` 开头的兼容 Hub 地址，先测试连接。 |

下载成功后，软件会显示本地缓存目录和“可直接识别”状态。此后点击“开始本地识别”只读取本地模型，不会再发起隐藏下载。若您切换到另一个未下载档位，软件会再次引导您选择来源和下载。

## 常见问题

若“测试连接”失败，请先切换官方源和国内镜像源分别测试；官方源失败通常意味着本程序没有通过 VPN/代理联网，镜像源失败则可能是镜像临时不可用或网络策略限制。自定义地址必须以 `https://` 开头，并且需要兼容 Hugging Face Hub 的模型仓库接口。

若下载中断，请检查磁盘空间和网络稳定性后重新点击“下载选中模型”。软件会将模型保存到当前用户的数据目录，下载完成后才会解锁对应档位的“开始本地识别”。项目文件、已导出的 SRT、LLM API 配置以及已下载的其他模型都不会被删除。

## 技术依据与参考资料

faster-whisper 在按模型名称加载时会从 Hugging Face Hub 自动取得相应的 CTranslate2 模型；本补丁改为在应用内先显式下载到本地目录，再按本地目录加载，从而避免识别开始时进行不可见网络访问。[1] Hugging Face Hub 的下载接口支持按调用指定端点，因而可以在一次下载中使用官方站、镜像或自定义兼容地址。[2]

[1] [faster-whisper 官方文档](https://github.com/SYSTRAN/faster-whisper)

[2] [Hugging Face Hub 下载与缓存文档](https://huggingface.co/docs/huggingface_hub/en/package_reference/environment_variables)
