# 《弦字幕》（LyraSub）基准版说明

**版本：** v260820  
**安装包：** `LyraSub-setup.exe`  
**补丁文件名：** `LyraSub-patch.exe`  
**出品：** 本工具由天琴工作室（Lyra Studio）出品 · 海舟（Lyrazhou）制作  
**Email：** fantasyland@163.com

## 安装与首次启动

请运行 `LyraSub-setup.exe` 完成安装。基准版会安装应用程序与必要运行组件，但**不会预下载语音识别模型**。首次在“文字识别”页面实际启动某个模型档位时，软件才会在当前 Windows 用户的数据目录下载模型；模型与应用安装目录相互独立，因此以后正常安装 `LyraSub-patch.exe` 时不会重复下载已存在的模型。

> 建议先从“平衡（默认）”档位开始。它面向常规中英文影视对白场景；“快速”适合草稿与短片测试，“高精度”适合最终校订前重跑识别。

| 操作阶段 | 用户操作 | 系统保存的内容 |
|---|---|---|
| 导入 | 选择 MP3 文件 | 本地路径、项目名称与音频元数据 |
| 识别 | 选择自动/中文/英文、模型与 GPU/CPU | 原始转写、词/字时间锚点、检测语言 |
| 清洗 | 选择是否调用用户配置的文本模型 | 原文、清洗文本、操作说明；不写入密钥 |
| 切分 | 设置每行 15 汉字 / 42 英文字符等目标 | 字幕条目、换行、锚点映射、风险状态 |
| 导出 | 设置全局偏移量，导出 SRT | SRT 文件；项目仍保留未偏移的原始锚点 |

## GPU、CPU 与模型下载

“自动”模式优先尝试可用的 NVIDIA GPU；如果 GPU 运行环境不可用或初始化失败，软件会明确提示并自动回退到 CPU。用户手动选择“NVIDIA GPU”时，若运行环境不满足要求，软件不会静默改为 CPU，而是会提示用户改选 CPU 或取消。

CPU 模式可以完成识别，但速度取决于音频长度与电脑性能。GPU 识别需要 Windows 可用的 NVIDIA CUDA 运行环境；如果电脑仅有 NVIDIA 显卡但缺少相应运行依赖，请先用“自动”模式验证，软件会显示最终实际使用的设备。

## 时间锚点与人工修改

每个可发声的词或中文字符尽量绑定来源音频的开始/结束时间。只调整换行或对原文进行小幅修改时，字幕会继承原锚点。新增、替换或大幅清洗后不能可靠对应原文的文字，会显示为“需复核”或“无锚点”。这是刻意的安全机制：系统不会把估算时间伪装成精确时间。

对于需要强制交付的条目，您可在“语义切分”表中直接填写开始与结束的毫秒时间，再在“校对导出”页复核。全局偏移量默认 `0 ms`；例如填写 `-200 ms` 会使导出 SRT 的每条字幕提前 0.2 秒显示，但不会修改项目中保存的原始锚点。

## LLM 文本服务与隐私

清洗与语义切分默认关闭。启用前，请在右侧“配置文本模型服务”中填写 OpenAI 兼容的 API 基础地址、模型名和 API 密钥。密钥会与项目文件分离保存，Windows 环境优先采用当前用户保护；项目 `.lyrasub` 文件、导出 SRT、默认配置导出与日志均不应包含 API 密钥。

每次使用 LLM 时，软件发送的是当前文本和切分约束，**不发送 MP3 源音频**。若服务不可用，您仍可手工编辑文字，并选择“本地规则切分”完成整个 SRT 流程。

## 项目文件和导出文件

建议在导出 SRT 的同时保存 `.lyrasub` 项目文件。该文件保留原始识别文本、清洗文本、时间锚点、字幕切分、偏移量和人工覆写信息，是未来接入波形编辑、拖拽校时与帧级复核的兼容基础。项目文件不嵌入模型，也不嵌入 API 密钥。

首版可导出如下文件：

| 文件 | 用途 |
|---|---|
| `.lyrasub` | 可再次编辑的项目文件，包含锚点与编辑状态 |
| `.txt` 原文 | 人工校订后的识别文本 |
| `.txt` 清洗文本 | LLM 或手工清洗后的文本 |
| `.txt` 分行文本 | 最终字幕条目的文字与换行 |
| `.srt` | 最终带时间码字幕 |

## 后续补丁

后续每次功能更新均使用同一个名称：`LyraSub-patch.exe`。补丁启动时会确认已安装基准版、确认当前版本符合目标更新起点、结束运行中的 `LyraSub.exe`、备份被覆盖的文件到安装目录 `.update-backup`，再替换实际变更文件。模型、用户项目、用户 API 配置及导出文件均不在补丁替换范围内。

因此，请不要用重命名补丁文件来表示版本；版本信息由补丁内部清单和软件“关于”页面控制。遇到更新异常时，保留 `.update-backup` 目录与项目文件，以便回退和排查。

## 已知边界

首版仅支持导入 MP3。说话人区分、多音轨/视频导入、全功能波形编辑、拖拽字幕时间、帧级校时、翻译与 ASS 样式字幕不属于首版范围，但项目结构已预留手工时间覆写和波形扩展字段。多人重叠说话、不可辨语音、严重噪声、音乐覆盖人声，以及清洗后大幅改写的文本均应进行人工时间复核。
