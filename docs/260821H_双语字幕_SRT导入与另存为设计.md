# LyraSub Plus v260821H：双语字幕、外部 SRT 与另存为设计

## 双语字幕数据原则

每条字幕继续以 `text` 保存原/主文本，并新增独立的 `translation_text` 保存 LLM 译文。翻译不会覆盖原文字、起止时间、手工时间或锚点。项目设置新增三项输出偏好：单语原文、单语译文或双语；双语时原文/译文谁在上；各自的语言名称。

双语模式在显示和 SRT 导出时强制采用两行：上、下行分别由用户指定的原文与译文构成。为避免把已有源文换行扩展成三行以上，双语渲染会把单条原文内部换行压缩为空格；用户仍可在编辑表保留原始换行并切换回单语模式。

## 批量翻译规则

翻译任务传输带稳定字幕 ID 的字幕数组，而不是逐条请求。每批由用户在“模型服务配置”中设定“翻译每批字符数”；默认 8,000，允许 1,000–100,000。批次在字幕边界处分割，绝不将单条字幕拆到两次请求中。若单条本身超过设置上限，则单独发送并显示提示。

每个请求要求 LLM 返回与输入 ID 一一对应的译文数组。应用在全部批次成功前不会写回工程；取消、超时或 ID 缺失都会丢弃本次未完整结果，保护既有翻译。后台任务按批次报告完成比例并复用现有“停止当前任务”和持续已用时显示。

## 外部 SRT 导入规则

外部 SRT 使用原始起止时间创建 `SubtitleEntry`：`start_ms`/`end_ms` 与 `manual_start_ms`/`manual_end_ms` 均写为 SRT 时间；`anchor_ids` 保持空数组；不创建伪造的词级或字级锚点。这类条目在表格中统一显示为“人工定时”，不会被标为“需复核：缺少锚点”。

导入后的项目可以正常保存、另存为、自动保存、手工改时间、导出 SRT、翻译和双语预览。进入语义切分页面时会显示人工定时提醒；任何会重新切分的操作都需要显式确认，因为它无法从无锚点项目自动继承时间。

## 另存为规则

“另存为…”将工程快照保存到新 `.lyrasub` 文件并立即把该文件设为当前工程路径；后续普通保存、自动保存和默认导出文件名都以新路径/现有项目名为准。原工程文件及其同目录自动保存恢复快照不被删除、不被改写。

## 兼容性

项目 schema 从 v4 升级至 v5。旧工程未含译文、输出偏好或 SRT 导入元数据时，按单语原文模式加载；没有锚点的 SRT 工程也完全合法。
