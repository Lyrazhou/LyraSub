# 《弦字幕》（LyraSub）v260820G 模型管理与 Pascal GPU 兼容说明

> **适用版本：** 已安装 **v260820F** 的《弦字幕》（LyraSub）。运行固定文件名 `LyraSub-patch.exe` 后将升级为 **v260820G**。

## 本次更新

v260820G 合并了两项关键改进。第一，模型下载、模型来源和网络代理设置已从“文字识别”工作台移出，集中到顶部工具栏的 **“模型管理”**。主工作台只负责选择本地已下载的模型、语言和运行设备，避免在识别前误点下载或反复进入下载流程。第二，GTX 1060 等 Pascal 架构显卡不再被错误强制使用 FP16；软件会查询 CTranslate2 实际支持的计算精度，并自动选用兼容模式。

| 改进 | v260820G 行为 |
|---|---|
| 独立模型管理 | 顶部工具栏新增“模型管理”，统一维护三档本地语音识别模型、下载来源、自定义镜像、代理、连接测试、下载进度与停止下载。 |
| 主工作台简化 | “文字识别”页仅保留主要语言、模型档位、运行设备、GPU 自检和“开始本地识别”。不再放置下载按钮或来源配置。 |
| 已下载状态 | 主工作台清楚显示所选模型是否已下载；未下载时识别按钮不可用，并引导打开“模型管理”。 |
| 下载复用 | 管理页会显示本机已经下载的模型与缓存位置。已下载模型的下载按钮自动禁用，补丁更新不会删除模型。 |
| GPU 精度自动选择 | 软件使用 `ctranslate2.get_supported_compute_types("cuda")` 查询实际 CUDA 支持能力，优先选 FP16，其次 INT8，最后 FP32。 |
| GTX 10 系兼容 | GTX 1060 等 Pascal GPU 无高效 FP16/Tensor Core 路径时，自动选用 **INT8**；无需重新下载快速、平衡或高精度模型。 |
| 可复制诊断 | GPU 自检会显示 CTranslate2 支持的计算精度与 LyraSub 的推荐精度，便于排查兼容性问题。 |

## 如何管理模型

在软件顶部工具栏点击 **“模型管理”**。在该窗口选择“快速”“平衡”或“高精度”，选择模型来源后可先点击“测试连接”，再点击“下载选中模型”。下载完成后，模型会自动成为主工作台的当前可用选择；以后再次打开软件和应用补丁时无需重复下载。

| 场景 | 正确操作 |
|---|---|
| 首次下载模型 | 顶部“模型管理” → 选择档位与来源 → 测试连接 → 下载。 |
| 识别音频 | “文字识别” → 选择已下载模型、语言、设备 → 开始本地识别。 |
| 模型尚未下载 | 主工作台状态会提示“打开模型管理”；不会显示下载来源或触发误下载。 |
| 切换下载源或代理 | 只在“模型管理”中调整；设置保存在当前 Windows 用户配置中。 |
| 取消正在下载 | 在“模型管理”窗口点击“停止下载”，未完成临时文件不会被当作可用模型。 |

## GTX 1060 / Pascal GPU 使用说明

对于 GTX 1060 6GB，请正常在“模型与设备”中选择 **“自动（选择兼容 GPU 精度）”** 或 **“NVIDIA GPU”**，再运行 GPU 自检。升级成功后，预期自检中会出现类似以下两行：

```text
CTranslate2 CUDA 支持计算精度：float32, int8, int8_float32
LyraSub 推荐 GPU 计算精度：int8
```

这表示软件会以 `int8` 计算精度加载现有模型。它不是 FP8，也不是需要重新下载的“FP8 模型”；CTranslate2 可以在模型加载阶段转换权重以适配设备能力。若自检推荐 `float16`，则该设备具备较新的高效 FP16 路径；若推荐 `float32`，则仍可尝试 GPU，但速度和显存效率会较低。

> 不建议通过 `CT2_CUDA_ALLOW_FP16=1` 强制 GTX 1060 使用 FP16。Pascal GPU 缺乏 Tensor Cores，CTranslate2 默认禁用该低效路径；INT8 是更合适的兼容模式。

## 补丁应用和验证

请关闭正在运行的 LyraSub，再执行 `LyraSub-patch.exe`。补丁仅接受 v260820F 安装状态，完成后会备份原 `LyraSub.exe` 和 `release-manifest.json` 到安装目录 `.update-backup\v260820G`。

升级后请进行以下实机验证：

1. 打开软件，确认顶部出现“模型管理”。
2. 打开“文字识别”，确认页面没有下载来源、代理和下载按钮。
3. 打开“模型管理”，确认能看到模型来源、下载状态和“本机已下载”摘要。
4. 在“模型与设备”运行 GPU 自检，确认 GTX 1060 的推荐精度为 `int8`。
5. 选择“快速”模型和 NVIDIA GPU，以短 MP3 执行一次实际识别。
