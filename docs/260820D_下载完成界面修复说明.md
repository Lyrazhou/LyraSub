# 《弦字幕》（LyraSub）v260820D 下载完成界面修复说明

**补丁文件：** `LyraSub-patch.exe`  
**升级路径：** `v260820C` → `v260820D`  
**适用问题：** 模型下载完成后出现“下载完成”窗口，但该窗口无法点击确认，主界面看似无响应，无法继续下载其他模型。

## 修复原因与方式

此前后台下载任务在工作线程中直接更新进度条、启用按钮并显示“下载完成”对话框。Qt 窗口控件只能在主界面线程操作；跨线程显示模态窗口会造成窗口事件循环阻塞，因此即使模型已完整写入，也可能无法点击确认。

本补丁增加主线程任务桥接器。下载线程现在只传递进度、成功、失败和完成事件；所有进度条更新、状态文本、完成弹窗、错误诊断窗口和按钮状态变化均回到主界面线程执行。完成一个模型下载后，后台任务引用会被释放，您可以立即选择另一个模型档位继续下载。

## 操作步骤

请完全退出《弦字幕》后运行 `LyraSub-patch.exe`。重新启动软件，进入 **02 文字识别**。已完成下载的模型会显示“可直接识别”；然后切换到其他模型档位，选择来源并继续点击“下载选中模型”。

| 操作 | 预期行为 |
|---|---|
| 快速模型下载完成 | “下载完成”窗口可以点击确认，主窗口保持响应。 |
| 切换到平衡或高精度模型 | “下载选中模型”按钮重新可用，可立即开始下一次下载。 |
| 下载过程中点击停止 | 按钮变为不可用并安全清理当前临时文件，界面不会冻结。 |
| 下载或连接失败 | 弹出可复制的诊断文本窗口，仍可正常关闭后重试。 |

发布前已执行静态检查和自动化测试，包括主窗口构建、后台完成回调必须在主界面线程执行、一次任务结束后连续启动两次下载式任务，以及 v260820C → v260820D 补丁版本校验、备份和冻结应用启动自检。
