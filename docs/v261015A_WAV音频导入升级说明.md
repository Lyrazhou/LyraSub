# 《弦字幕 Plus》（LyraSub Plus）v261015A：WAV 音频导入升级

## 本次更新

v261015A 在原有 MP3 音频与带音轨 MP4 视频之外，新增 WAV 音频的完整导入与本地识别支持。

- **新建项目**：文件选择器可选择 WAV；导入后显示 WAV 媒体类型并自动以文件名建议项目名。
- **本地识别**：WAV 源文件通过 faster-whisper 的媒体解码路径直接识别，不需要用户先手工转换成 MP3；生成的文本与词级/字级时间锚点沿用现有流程。
- **工程保存与继续**：WAV 源文件路径保存在 `.lyrasub` 工程中，保存、关闭并重新打开工程后仍可继续识别/校对。
- **分段工作流**：添加章节 SRT 或工程时，可将对应 WAV 作为该章节的关联音频。
- **既有行为**：MP3、MP4、SRT、双语字幕、LLM 配置、校对、视频预览与时间轴均维持原有逻辑。

## 兼容与要求

本次仅扩展可接受的媒体后缀与界面文案，现有项目 schema 无需迁移。WAV 是否能解码仍取决于文件本身是否为有效、未损坏且使用可支持编码的 RIFF/WAVE 音频；压缩型或损坏的 WAV 仍可能被解码器拒绝。识别继续在本地运行，不会因为选择 WAV 而上传媒体内容。

## 版本信息

- 版本：**v261015A**
- 完整安装包：`LyraSub-Plus-setup.exe`
- 安装目标沿用现有 LyraSub 安装目录；安装器不会清除用户工程和模型数据。
