# 《弦字幕 Plus》（LyraSub Plus）v260821E 发布与迁移说明

## 版本定位

v260821E 是 **《弦字幕 Plus》（LyraSub Plus）**的首个完整基准安装版。它在标准版《弦字幕》（LyraSub）v260821D 的全部识别、清洗、语义切分、锚点映射、校对和导出能力之上，增加了面向章节化长片的**分段合并与全局时间轴**工作区。

标准版 v260821D 已单独归档留存。今后的功能演进以 Plus 版为基线。

## 安装与迁移

Plus 安装包继续使用标准版的安装目录：

```text
%LOCALAPPDATA%\LyraSub
```

因此，安装 Plus 时会直接覆盖标准版应用程序，而不会要求用户重新下载本地识别模型、重新配置 LLM 服务或迁移工程文件。安装器会将开始菜单与桌面快捷方式更新为“弦字幕 Plus（LyraSub Plus）”，并将卸载信息显示为 Plus 版。标准版的 `.lyrasub` 工程可继续直接打开。

> 安装前应先退出正在运行的标准版或 Plus 版。Plus 安装包是完整安装版，不是标准版 v260821D 的差分补丁。

## 分段合并工作区

Plus 在左侧流程末尾新增“**06 分段合并**”。该工作区支持导入多个章节 SRT，或导入多个已完成校对的 `.lyrasub` 章节工程；每个片段可选择一个对应 MP3 以启用章节试听和连续起点计算。

| 能力 | 说明 |
|---|---|
| 章节来源 | 支持 SRT 和弦字幕工程；工程导入会读取该工程的实际导出时间 |
| 全片起点 | 可为每段输入绝对全片起点，例如 `00:42:18.000` |
| 连续定位 | 可设置“与上一段连续”及章节间隔；软件根据上一段 MP3 时长自动计算当前片段全片起点 |
| 全局换算 | 每条字幕按 `全片时间 = 片段起点 + 本地时间` 换算，重新排序并重新编号 |
| 冲突校验 | 提示起点未确认、章节顺序倒置、片段内部重叠和跨段字幕重叠 |
| 合并预览 | 以全片时间轴定位字幕；若对应 MP3 可用，点击全片字幕行或拖动时间轴即可跳到对应章节本地位置试听 |
| 合并工程 | 可保存为独立 `.lyrasubmerge` 文件，不改写任何原章节工程或原 SRT |
| 全片导出 | 通过校验后导出一份全局连续时间码的 SRT |

### 推荐工作流

1. 将电影或超长音频按章节、场景或自然边界裁成多个 MP3。
2. 每段分别使用普通识别、清洗、自然语义切分与校对流程，保存 `.lyrasub` 工程或导出章节 SRT。
3. 打开“06 分段合并”，按顺序添加每段 SRT/工程及其对应 MP3。
4. 第一段通常设为全片 `00:00:00.000`；之后每段填绝对全片起点，或选择“与上一段连续”并填章节间隔。
5. 使用“检查合并时间轴”处理黄色警告与跨段重叠。
6. 在全片表中点击定位，双击需要精修的字幕；保存 `.lyrasubmerge` 后导出全片 SRT。

## 时间概念说明

| 概念 | 作用 | 示例 |
|---|---|---|
| 片段本地时间 | 章节 MP3 内的时间，永远从 0 开始 | 第二章 `00:00:12.500` |
| 片段全片起点 | 第二章本地 0 秒在全片中对应的位置 | `00:42:18.000` |
| 全片字幕时间 | 合并后输出的 SRT 时间 | `00:42:30.500` |
| 交付偏移 | 全部字幕最后统一提前/滞后显示的可选处理 | 例如全片提前 200 毫秒 |

片段全片起点与常规字幕交付偏移必须分开：前者负责建立章节的绝对坐标，后者只在最终交付阶段应用一次。

## 本轮界面优化

| 项目 | 变化 |
|---|---|
| 自动保存入口 | 不再单独占用一行菜单栏；顶部“自动保存”位于“关于”左侧 |
| 大字号清洗编辑 | 使用窗口级 **20 px** 正文字号，相对主界面 13 px 正文约为 1.5 倍以上，并可用按钮继续放大或缩小 |
| 品牌显示 | 窗口标题、应用名、关于信息、安装器、开始菜单、桌面快捷方式和卸载项均更新为 LyraSub Plus |
