# 《弦字幕》（LyraSub）v260821B 发布说明

## 概述

**v260821B** 聚焦于语义切分与校对导出阶段的可用性：工作台可释放更多编辑宽度，字幕编辑不再依赖狭窄的行内输入，校对页新增 MP3 播放、时间轴定位与字幕叠加预览。本次完整安装包同时包含后续交互微调：精简 LLM 切分按钮文案、点击序号列定位播放指针，以及句间保持空白的预览显示。

| 区域 | 本次变化 | 使用收益 |
|---|---|---|
| 右侧项目检查器 | 顶部新增“隐藏检查器 / 显示检查器”开关 | 表格与长字幕文本可获得更宽的工作区 |
| 字幕表格 | 支持列宽拖动、右键菜单与双击弹窗编辑 | 减少误编辑，适合处理长字幕和两行字幕 |
| 校对导出页 | 表格获得弹性高度，底部加入 MP3 字幕预览 | 可在导出前同步复核文本、时间码和显示节奏 |
| 页面信息层级 | 移除两侧底部说明性卡片 | 为表格和时间轴释放有效垂直空间 |

## 字幕编辑工作流

切分页与校对页的字幕表格均已取消直接行内修改。对任意字幕行**双击**，或使用**鼠标右键**选择“修改文字…”，即可打开可输入多行文字的编辑窗口。保存后，软件会立即以编辑后的文本重建其与原始词级时间锚点之间的映射；若文字改动无法可靠继承锚点，条目仍会按既有规则标记为待人工复核。

右键菜单提供“修改文字…”“拆分为两条”“与下一条合并”和“确认已人工复核”四项操作。右键触发的拆分或合并会立即保存并重新映射时间锚点；底部原有按钮仍予以保留，便于习惯旧工作流的用户先连续调整多行，再统一点击“保存表格修改并重新映射”。

## MP3 字幕预览

校对导出页底部的“MP3 字幕预览”区域会自动加载当前工程关联的 MP3 文件。点击“播放”后，时间轴会持续更新，软件会根据播放位置和全局偏移量显示当前字幕，并在校对表中选中、滚动到对应条目。再次点击按钮即可暂停。

| 控件 | 行为 |
|---|---|
| 播放 / 暂停 | 开始或暂停当前工程的 MP3 预览 |
| 时间轴滑块 | 按住并拖动以快速定位；松开时音频跳转到目标时间 |
| 当前时间与总时长 | 以 `HH:MM:SS.mmm` 形式显示播放位置与媒体总时长 |
| 字幕叠加区 | 显示当前时间点应出现的字幕；句间空白时保持空白，不写入最终 SRT |
| 序号列 `#` | 在校对表点击某条字幕的序号，可将播放指针定位到该条的显示开始时间 |
| 全局偏移量 | 校对表、SRT 导出和预览同步应用，不会改写原始词级锚点 |

若工程记录的 MP3 路径已失效，预览区域会明确提示重新导入或恢复文件路径；字幕表格编辑与 SRT 导出不受影响。

## 升级与兼容性

本补丁的目标版本是 **v260821B**，其安装校验基线为 **v260821A**。因此它适用于已经安装 v260821A 补丁的用户，可直接完成 v260821A → v260821B 升级；既有 `.lyrasub` 工程格式保持兼容，项目名称、自动恢复草稿、词级锚点、两行字幕模式与人工复核标记均会保留。

> 建议在升级前先保存当前工程文件。安装补丁时请退出正在运行的《弦字幕》，运行新的 `LyraSub-patch.exe` 后按窗口提示完成覆盖与备份。若此前下载过本次补丁的旧文件，请删除旧文件并以本次替换附件为准。

## 完整安装包

本次同时提供 **`LyraSub-setup.exe` 完整安装包**。它适用于首次安装、希望重新安装全部应用组件，或不希望处理版本基线校验的用户；安装程序会写入 v260821B 注册版本，并保留用户本地的识别模型缓存目录。若系统中已经安装旧版，建议先退出应用后运行完整安装包并保持默认安装目录。

## 手工插入字幕与时间围栏

校对导出页现在支持为静音、音乐或未识别段落添加人工字幕。暂停播放后，点击预览控制区的“在此处插入字幕”，软件会检查播放指针是否位于既有字幕之外的空档；若可插入，会以播放位置为开始时间，在相邻空档内自动分配最多两秒的结束时间，并打开文字输入窗口。用户输入文字并保存后，条目会以人工定时方式写入工程，不会改变原始词级锚点。

也可以在校对表中右键任意条目，选择“插入下一行…”。新条目将从当前条目的结束时间开始，并且不会超过下一条字幕的开始时间。没有可用正时长空档时，软件会拒绝插入并说明原因，而不会压缩或覆盖既有字幕。

起止时间的调整可通过双击校对表的“开始”或“结束”单元格，或在右键菜单选择“调整起止时间…”。对话框会显示上一条的结束时间、下一条的开始时间以及可编辑范围。开始时间不得早于上一条结束时间，结束时间不得晚于下一条开始时间，并且结束必须晚于开始；未通过校验的改动不会写入工程。
