# 工作台视觉核对记录

**核对尺寸：** 1600×900（对应用户要求的 1920×1080 可用工作区基准下的默认窗口尺寸）

正式深色主题的工作台已完成视觉核对。顶部项目命令、左侧五步制作导航、中央主编辑区、右侧项目检查器和底部状态栏同时可见；导入页的文件选择与“时间轴保障”说明在首屏可操作。中央区在当前尺寸下留有足够的纵向扩展空间，长文本/表格页面可由各自滚动区域承载，不需要缩小关键编辑内容。

视觉层级采用近黑蓝灰背景、青蓝色主操作和琥珀色风险状态的设计。该效果与“专业 + 影视感”的定位一致。后续发布前仍应在真实 Windows 10/11 的 100%、125% 和 150% 缩放下复核系统字体、任务栏可见性与窗口最小尺寸。
