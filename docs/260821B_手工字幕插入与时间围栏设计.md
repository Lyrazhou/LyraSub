# v260821B 手工字幕插入与时间围栏设计

## 适用范围

本设计仅作用于“校对导出”阶段。语义切分生成的原始词级锚点始终保留；用户在静音、音乐或未识别片段中插入的字幕不伪造语音锚点，而是作为具有人工起止时间的独立字幕条目保存。

| 操作入口 | 插入位置 | 初始时间 | 保存方式 |
|---|---|---|---|
| 播放控制区“在此处插入字幕” | 当前暂停播放位置所在的相邻字幕空档 | 从播放指针开始，默认占用空档内最多 2 秒 | 写入手工起止时间，并标记为已人工复核 |
| 校对表右键“插入下一行” | 当前选中条目的下一条 | 从当前条目结束开始，默认占用后续空档内最多 2 秒 | 写入手工起止时间，并标记为已人工复核 |

如果播放指针处于既有字幕时间段，或两个相邻字幕之间没有正时长空档，系统不插入并说明原因。这可以避免默认操作无意覆盖已有字幕。

## 时间围栏

对于第 `i` 条字幕，系统以相邻字幕的有效时间建立约束。开始时间不得早于第 `i-1` 条的结束时间；结束时间不得晚于第 `i+1` 条的开始时间。开始时间必须严格早于结束时间，并且时间值不得为负。相邻条目没有有效时间时，对应一侧不施加相邻围栏；若音频总时长已知，仍以媒体总时长作为末尾约束。

| 用户动作 | 校验结果 |
|---|---|
| 开始时间早于上一条结束时间 | 拒绝保存，并显示上一条结束时间 |
| 结束时间晚于下一条开始时间 | 拒绝保存，并显示下一条开始时间 |
| 开始时间不小于结束时间 | 拒绝保存，要求保持正时长 |
| 时间处于可用空档 | 以 `manual_start_ms` 与 `manual_end_ms` 保存，不改写原始锚点 |

全局偏移量仅影响预览、校对显示与 SRT 导出。用户在编辑对话框中维护的是工程的原始毫秒时间，因此围栏判断不会因预览偏移量而失真。
