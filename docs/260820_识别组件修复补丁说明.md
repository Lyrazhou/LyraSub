# 《弦字幕》（LyraSub）v260820 识别组件修复补丁说明

**补丁文件：** `LyraSub-patch.exe`  
**适用对象：** 已安装 `LyraSub-setup.exe` 基准版 v260820 的用户  
**补丁版本显示：** 仍为 `v260820`；本次为同日内部修订，不改变约定的 `vYYMMDD` 关于页版本格式。

## 本次修复

本补丁修复了首个基准安装包中“文字识别”页点击开始后可能显示 **“缺少识别运行组件”** 的问题。根因是基准安装包包含了本地识别库的 Python 模块，却遗漏了其依赖的 Windows 原生动态库目录；程序因此在首次模型下载之前就中断，无法给出模型下载流程。

补丁补齐了本地音频解码与数值计算所需的原生运行库，并更新识别组件加载路径。修复后，程序会先正常加载本地识别运行组件，随后在您第一次选择模型并点击“开始本地识别”时，才下载相应的语音模型。

> 本补丁**不包含 Whisper 识别模型本体**。模型仍按原设计，在首次实际识别时由程序下载并缓存；以后继续安装常规补丁时不会重复下载已存在的模型。

## 安装方法

请先彻底退出《弦字幕》，然后直接运行附件中的 `LyraSub-patch.exe`。补丁只适用于 v260820 基准版；它会自动检查已安装版本、结束仍在运行的主程序、备份替换文件并完成更新。完成后重新打开《弦字幕》，进入“文字识别”页，选择语言、模型档位和运行设备，再点击“开始本地识别”。

补丁文件名固定为 `LyraSub-patch.exe`，不需要也不建议手工改名。应用目录下的 `.update-backup\v260820` 会保留本次替换的旧文件，供异常排查与回退使用。用户已下载的模型、`.lyrasub` 项目文件、API 配置和已经导出的 SRT 都不会被补丁删除或覆盖。

## 验证结论

修复版已在与基准安装包隔离的 Windows 环境中执行以下验证：基准版安装、实际 `LyraSub-patch.exe` 更新、修复后冻结应用的识别组件自检、原生运行库存在性检查，以及旧主程序文件备份检查均已通过。
