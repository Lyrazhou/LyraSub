# 《弦字幕 Plus》（LyraSub Plus）v260821F：MP4 导入与视频预览说明

## 新增能力

LyraSub Plus v260821F 现在可在第一步“**导入媒体**”中选择 MP3 或 MP4。选择 MP4 后，软件会直接使用视频容器内的音轨进行本地语音识别，并保留该 MP4 的原始时间轴；不会在用户磁盘中另行生成一份长期保存的 MP3 副本。

在第五步“**校对导出**”中，MP4 项目会启用“**打开视频预览**”。该窗口与校对页共享同一播放状态，因此播放、暂停、拖动时间轴、点击字幕序号定位和当前字幕高亮会同步作用于视频画面与校对表。

## 导入和识别流程

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 在“导入媒体”选择 `.mp3` 或 `.mp4` | 工程保存原始媒体路径；默认项目名取文件名 |
| 2 | 在“文字识别”选择模型、语言和设备后开始识别 | 本地识别引擎从 MP3 或 MP4 音轨读取声音，生成文字与词级/字级锚点 |
| 3 | 完成清洗、语义切分和校对 | 字幕时间仍以原始媒体零点为基准 |
| 4 | MP4 项目在“校对导出”点击“打开视频预览” | 视频画面、时间轴和当前字幕同步显示 |
| 5 | 导出 SRT | 与 MP3 流程相同；全局字幕偏移仍只在预览和导出阶段统一应用 |

> MP4 不需要先被手动转换成 MP3。faster-whisper 经由其媒体解码链读取容器中的音频流，因此可保持视频与识别锚点共用同一时间坐标。

## 视频预览使用说明

视频预览窗口是非模态窗口，可以在校对表旁边持续打开。校对页中的“播放/暂停”和拖动时间轴仍是唯一的播放控制中心；视频窗口仅负责显示画面和当前字幕，因此两处不会出现不同步的独立播放头。

用户在校对表点击 `#` 序号列时，主播放器会跳转至该字幕起点；视频窗口随之定位到同一帧附近。用户手工调整字幕起止时间或全局偏移后，主预览标签和视频窗口中的当前字幕会在下一次时间轴更新时同步刷新。

## 兼容性与边界

| 项目 | 当前行为 |
|---|---|
| 支持格式 | MP3 音频与带可解码音轨的 MP4 视频 |
| MP4 无音轨 | 识别阶段会报告媒体解码/转写失败；应换用带音轨的源文件 |
| 视频编解码器 | 视频预览依赖随安装包提供的 Qt 多媒体/FFmpeg 后端；极少数特殊编码或受损文件可能无法显示画面，但不影响使用可单独提取的音频进行识别 |
| 音视频同步 | 使用同一 `QMediaPlayer` 实例和同一媒体时间轴；不创建第二个独立视频播放头 |
| 长片分段 | MP4 章节仍可分别处理，并在“分段合并”中用章节全片起点建立统一 SRT 时间轴 |
| 原始媒体 | 工程只记录路径；移动、改名或删除 MP4 后，重新打开工程需重新导入或恢复正确路径 |

## Plus 标题统一

工作台顶部标题、应用窗口标题、视频预览窗口、导入页、安装器、开始菜单、桌面快捷方式、关于信息和卸载显示均使用“**弦字幕 Plus（LyraSub Plus）**”标识。顶部副标题更新为“**LYRASUB PLUS · 影视字幕工作台**”。

## 验证状态

本版本通过 53 项单元测试和 17 项离屏界面回归测试，覆盖 MP4 媒体许可、视频预览入口、视频窗口字幕同步、关闭视频输出、Plus 标题和既有 MP3/分段合并流程。还在隔离 Windows 安装状态中完成了 v260821E 到 v260821F 的同目录完整安装覆盖验证，注册版本与发布清单均更新为 v260821F。
