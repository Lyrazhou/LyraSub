# 《弦字幕 Plus》v260821K 发布说明

**版本：v260821K**  
**产品：弦字幕 Plus（LyraSub Plus）**  
**发布形式：v260821J → v260821K 累积差分补丁**

> 本版本让当前文本模型在工作台中可见，明确清洗、切分与翻译三个阶段的标点职责，并将切分页的主确认动作改为直接进入校对导出。

## 本版更新

| 项目 | v260821K 行为 |
|---|---|
| 项目检查器中的文本模型 | 右侧“项目检查器”新增“文本模型服务”区，显示当前活动 Profile 名称、模型名及 API 密钥可用状态。不会显示 API Key、接口地址或其他敏感值。 |
| 清洗文本的标点 | LLM 清洗提示词明确要求保留原有标点句读，不以空格替代标点，也不人为添加词间空格。清洗阶段仅负责去除口语赘词、明显重复、无意义停顿和多余空白。 |
| 语义切分的标点 | 切分提示词新增第 6 条：中文正文删除常规全角标点；若该标点原本分隔两个仍应可读的中文语义片段，以一个普通空格替换，避免连续空格。 |
| 切分时的保护规则 | 不删除或拆坏英文单词、缩写、所有格、连字符词、数字、小数、日期时间、URL、邮箱、专名或技术记号。换行仍仅用于同一字幕的两行版式。 |
| 翻译字幕的标点 | 翻译系统提示词和实际请求规则一致改为：删除常规句读标点，同时保留英文撇号 `'`、连字符 `-`，以及专名、缩写、数字、小数、日期时间、URL、邮箱、货币和技术记号。 |
| 切分页主确认按钮 | 原“保存表格修改并重新映射”改为 **“应用切分修改并进入校对导出”**。点击后会将文字、拆分/合并和手工时间写入工程，重新映射词级锚点，并自动跳转至“05 校对导出”。 |

## 文本阶段职责

| 阶段 | 标点行为 | 空格行为 |
|---|---|---|
| 本地识别 / 原文校订 | 按识别或用户输入保留 | 不做强制词间空格处理。 |
| LLM 清洗 | 保留原有标点句读 | 清理多余空白，但不以空格替代标点。 |
| 语义切分 | 删除中文常规全角标点 | 仅在原标点所分隔的中文语义片段仍需同屏可读时，用一个普通空格替代。 |
| LLM 翻译 | 删除目标字幕中的常规句读标点 | 删除标点后不产生连续空格；必要英文及技术记号受保护。 |

因此，清洗文本中出现“大家好！我是海舟。”是符合本版设计的；进入语义切分后，LLM 可以输出“大家好 我是海舟”。空格在这里表示两个短而独立的自然意群在同一阅读节拍内同屏出现，而不是清洗阶段无差别删除标点的副作用。

## 项目检查器中的模型信息

清洗、自然语义切分和 LLM 批量翻译始终使用“模型服务”窗口中所选择的当前活动 Profile。v260821K 会在项目检查器中显示：

- **当前 Profile**：例如“主服务”或“备用模型”；
- **当前模型**：例如服务商配置的模型名称；
- **密钥状态**：显示“密钥可用”或“API 密钥不可用”。

工程文件不会保存 API Key。切换、修改、新建或删除 Profile 后，保存配置即可刷新检查器显示。

## 切分确认与锚点映射

“应用切分修改并进入校对导出”不是简单的翻页按钮。它会读取字幕编排表格，依据用户修改的文字重新匹配初始语音识别得到的词级/字级锚点；如果可见起止时间与新映射的自动时间不同，则保存为人工定时覆盖。拆分或合并后也会据此产生正确的连续字幕时间关系。

即使表格没有新的修改，点击该主按钮也会进入“05 校对导出”，便于把它作为明确的阶段确认动作。右键菜单中的拆分、合并等局部操作仍在当前切分页原地应用，不会强制跳转。

## 已保存的自定义提示词

提示词模板可由用户在“模型服务”的高级提示词入口中自行修改并保存。为保护既有自定义内容，软件不会覆盖本机已经保存的模板；如需采用本版新的默认标点规则，请在提示词窗口中使用对应的**恢复默认**功能，然后按需要再次调整。

## 验证

本版本已完成代码格式化和静态检查。完整测试 **71 项通过**，离屏界面冒烟测试 **25 项通过**，覆盖当前 LLM Profile 与模型显示、密钥敏感值隐藏、切分确认后自动进入校对导出、清洗保留标点、切分去除中文常规标点，以及翻译去除常规句读并保护必要特殊记号。
