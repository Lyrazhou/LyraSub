# 《弦字幕》（LyraSub）v260820H 工程续作与自动恢复说明

> **适用版本：** 已安装 **v260820G** 的《弦字幕》（LyraSub）。关闭软件后运行固定文件名 `LyraSub-patch.exe`，即可升级为 **v260820H**。

## 更新概述

v260820H 为字幕制作工作流加入完整的**中间状态续作**能力。用户可以在识别后、LLM 清洗建议未确认时、字幕切分与手工校时进行到一半时保存工程并退出；下次打开 `.lyrasub` 工程文件后可继续工作。软件同时每 45 秒在工程文件旁写入独立恢复快照，用于应对意外关闭、断电或应用异常退出。

| 功能 | 行为 |
|---|---|
| 工程草稿 | 工程文件会保存原文编辑框、清洗编辑框、切分表的当前文字与毫秒时间、当前工作页面和草稿时间。草稿与已确认的词级时间锚点分开保存。 |
| 正常保存 | 按 `Ctrl+S` 或点击顶部“保存”时，已确认工程数据和未确认编辑草稿会一并写入 `.lyrasub` 文件。 |
| 自动保存 | 对已命名工程，只要存在未保存编辑，软件每 **45 秒** 在同目录生成隐藏恢复文件：`.工程名.autosave.lyrasub`。它不会覆盖用户正式工程。 |
| 崩溃恢复 | 下次打开工程时，如检测到恢复文件，软件会询问是否恢复。选择“是”可恢复上次快照中的阶段成果与未确认编辑；选择“否”会丢弃该恢复快照。 |
| 退出保护 | 有未保存编辑时，打开其他项目、新建项目或退出应用均会显示 **保存 / 不保存 / 取消**。选择“保存”会先写入工程；选择“不保存”会删除对应恢复快照；选择“取消”继续留在当前工作台。 |
| 后台任务边界 | 识别、LLM 清洗、LLM 切分和锚点映射运行中仍不能直接关闭应用。请等待其完成，或点击“停止当前任务”；未完成任务本身不支持从 50% 等进度断点续跑。 |

## 可保存的制作中间状态

| 当前进度 | 可保存和续作的内容 |
|---|---|
| 识别完成、尚未清洗 | 源 MP3 路径、识别文本、检测语言、词级/字级时间锚点、识别设备设置。 |
| 清洗建议已返回但尚未点击确认 | 清洗编辑框中的文本草稿会被保存；恢复后仍显示在清洗页，不会擅自覆盖已确认的锚点或文本。 |
| 切分表编辑一半 | 每一条字幕当前文字、换行、开始毫秒与结束毫秒都会保存为草稿；恢复后用户可继续编辑，随后再点击“应用表格编辑并重建锚点映射”。 |
| 精调时间码一半 | 表格中的未应用时间码会被保存为草稿；偏移量、行长和设备选择也会随工程保存。 |
| 已完成切分但尚未导出 | 字幕条目、关联锚点、手工时间码、风险状态和导出偏移会保留。 |

> **重要区别：** 草稿恢复会原样恢复编辑界面，但不会自动把未确认表格内容重新映射到锚点。这样可避免在用户还未确认时改变已保存的原始时间轴。恢复后请在适当时机点击“应用表格编辑并重建锚点映射”。

## 使用建议

开始较长项目后，建议尽早按 `Ctrl+S` 创建正式 `.lyrasub` 工程。此后可随时继续编辑；自动保存仅作为兜底恢复，不替代正式保存。工程文件仅记录 MP3 的本机路径而不复制音频本体，因此请不要移动、改名或删除已关联的 MP3 文件；若路径失效，可重新导入同一音频后继续使用项目文本与锚点数据。

当右侧清洗文本或切分表正在编辑时，不再需要先点击“确认清洗”或“应用表格编辑”才能临时退出。直接保存即可保留草稿；下次打开后继续编辑并在确认时再应用即可。

## 升级、兼容与回滚

v260820H 将工程文件格式升级为 **schema v2**，以存储草稿。它保持对 v1 历史工程的读取兼容；首次保存旧工程后会升级为 v2。补丁运行前会检查版本，且仅适用于 v260820G；原 `LyraSub.exe` 与发行清单会备份到安装目录 `.update-backup\v260820H`，可用于回滚。
