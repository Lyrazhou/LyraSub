# 《弦字幕 Plus》（LyraSub Plus）v260821G：MP3 工程独立高清视频预览

## 适用场景

本补丁解决“识别时使用轻量 MP3，校对时才加载高清视频”的工作流。用户可以先导入 MP3 完成识别、文本清洗、自然语义切分和字幕校对；当需要核对画面与对白时，再在“校对导出”页选择对应的 MP4。高清视频只用于播放画面与试听，不会触发重新识别，也不会修改已保存的锚点、字幕文本或时间轴。

## 操作步骤

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 使用 MP3 创建或打开既有 `.lyrasub` 工程 | MP3 仍是唯一的识别源和原始锚点来源 |
| 2 | 进入“05 校对导出” | 打开“媒体字幕预览”区域 |
| 3 | 点击“选择预览视频…” | 选择对应同版本剪辑的 MP4 高清视频 |
| 4 | 点击“打开视频预览” | 视频画面与校对页播放、暂停、拖动时间轴、序号定位和字幕高亮同步 |
| 5 | 保存工程 | 工程仅保存 MP4 的本地路径，不复制或嵌入视频文件 |
| 6 | 需要恢复音频预览时点击“清除预览视频” | 预览播放器立即回到原识别 MP3；字幕数据不变 |

## 工程数据与安全性

v260821G 将工程 schema 升级至 v4，在原有识别源字段旁保存一个可选的 `preview_video_path`。这两个路径的职责严格分离。

| 字段 | 含义 | 对识别和锚点的影响 |
|---|---|---|
| `source.path` | 用于识别的 MP3 或 MP4 源媒体 | 原始识别文本、词级/字级时间锚点的唯一来源 |
| `preview_video_path` | 校对阶段临时/长期绑定的高清视频 MP4 路径 | 仅决定播放器显示的画面和音轨；不重映射任何字幕 |

旧版工程没有该字段时仍可直接打开。自动保存快照也会保存预览视频路径；若视频文件之后被移动或删除，软件会提示重新选择或清除预览视频，工程中的 MP3、字幕和锚点仍可正常使用。

## 对齐提醒

外部 MP4 应与用于识别的 MP3 来自同一剪辑版本并保持相同起点。软件刻意不会根据时长差异自动缩放字幕或改写时间码，以避免无声破坏锚点。如果 MP4 的片头、片尾或插播内容与 MP3 不同，请先在视频剪辑工具中对齐媒体，或在校对表中人工复核受影响的字幕时间。

## 补丁适用版本与验证

`LyraSub-patch.exe` 为 **LyraSub Plus v260821F → v260821G** 的差分补丁。安装前应退出应用。补丁保留更新备份目录，已在 v260821F 隔离安装副本上实际验证版本覆盖、发布清单更新、运行时自检和备份目录创建。

本次还完成了 54 项单元测试与 18 项离屏界面回归测试，覆盖外部 MP4 绑定、清除后恢复 MP3、工程 schema v4 保存恢复、旧版工程兼容、校对预览和既有分段合并流程。
