# 弦字幕（LyraSub）v260821A 切分校对与简体规范说明

**v260821A** 是以完整基准版 v260821 为基础的差分补丁。它重构了字幕切分与校对编辑的关键交互，解决了两行字幕不易辨认、黄色复核状态含义不清、表格应用操作不透明、校对页条目数易被误解，以及识别结果混用繁简中文的问题。

## 升级方式

请先完全退出 LyraSub，再在已安装 **v260821** 的电脑上运行固定文件名 `LyraSub-patch.exe`。补丁会替换应用核心和所需的繁简转换资源，并在应用目录保留升级前文件副本。已有工程可直接打开；工程文件会在下一次保存时从 schema v2 升级为 schema v3，旧版工程仍保持可读。

## 1. 单行与两行字幕显示模式

在“字幕编排”页面的 **显示模式** 中可选择以下方式：

| 模式 | 行为 | 推荐场景 |
|---|---|---|
| **每条仅一行（推荐）** | LLM 返回的一处换行会被转换为两条连续字幕，分别拥有独立时间段。 | 需要逐条精调、偏好每句字幕仅一行的影视工作流。 |
| **允许一条最多两行** | 保留同一个 SRT 编号内的换行，使两行文本在同一时间段同屏显示。 | 单句较长、希望保持一条语义完整字幕的排版。 |

15 个汉字只是阅读上限，不是凑满目标。LLM 仍优先按自然意群、短句同屏、语气与阅读节奏切分；软件负责将其结果转换为您选择的单行或两行排版。

## 2. 拆分与合并字幕

在字幕表中单击选中一行后，可以使用以下操作：

| 操作 | 用途 | 时间处理 |
|---|---|---|
| **拆分为两条连续字幕** | 将当前句拆为前后两条；如果原句已有两行，软件会自动将两行预填为两条文本。 | 软件按两段文字长度初步分配时间边界，您可在弹窗中修改文本，并在表格中继续调整毫秒。 |
| **与下一条合并** | 将当前字幕与后一条合成一条。 | 合并后的结束时间继承下一条的结束时间。 |
| **保存表格修改并重新映射** | 将表格中的文字修改映射回永久保留的词级时间锚点。 | 仅在表格确有文字或时间变化时执行；未改动时不会重新映射，也不会将自动时间冻结为手工时间。 |

拆分或合并后，先点击 **“保存表格修改并重新映射”**，再按 `Ctrl+S` 保存工程。这样下次打开仍可继续工作。

## 3. 黄色“需复核”与人工确认

黄色不是“句子太长”或“包含两行”的提示。它表示该条字幕包含新增、替换或无法从原识别文本继承的文字，因此时间由软件估算，或者没有可用时间锚点。

| 状态 | 含义 | 处理方式 |
|---|---|---|
| **需复核：估算时间** | 新增/大幅修改文字的时间在相邻锚点间估算。 | 检查文字与起止毫秒；需要时手工填写时间。 |
| **需复核：缺少锚点** | 该条无法获得可用的自动时间。 | 手工填写起止毫秒后再确认。 |
| **人工复核 ✓** | 用户已检查并明确确认该条。 | 绿色显示，不再计为黄色待复核项。 |
| **人工定时** | 当前起止毫秒由用户手工输入。 | 可继续导出，也可再次编辑。 |

选中黄色行并完成检查后，点击 **“确认已人工复核”**。校对页顶部、右侧检查器和字幕表均会使用同一套状态与条目数量。

## 4. 校对页条目数

“字幕编排”和“交付校验”始终使用同一组字幕记录。校对表可视区域一次只能显示部分行时，请在表格内部向下滚动；顶部会显示总条目数。例如“共 11 条”意味着导出会按 11 条处理，而不是只处理当前可见的前 5 条。

## 5. 默认统一简体中文

“字幕编排”页新增 **自动统一简体中文**，默认启用。它会将新的识别结果、LLM 清洗结果和 LLM 切分结果中的繁体字转换为简体字，同时保留英文、数字、标点和用户在表格中的手工输入。要处理旧工程，进入“可选增强”页面并点击 **“统一当前文本为简体”**；该操作会同步规范原文、清洗文本、锚点和现有字幕条目，然后可继续人工编辑。
